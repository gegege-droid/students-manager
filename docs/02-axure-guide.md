# Axure 制作指导 —— 成绩管理系统原型

> 面向 **Axure RP 10 / 11**。本文按「实际动手顺序」编排：建工程 → 定规范 → 做母版 → 搭页面 → 连交互 → 发布导出。
> 每一节都可以独立照做。文中 `【操作】` 是具体点击路径，`【要点】` 是容易失分的地方。

---

## 0. 开工前的准备

### 0.1 环境

| 项目 | 建议 |
|---|---|
| 工具 | Axure RP 10 或 11（团队统一一个版本，避免 10/11 之间打开错位） |
| 许可证 | 官网 30 天试用即可满足课程作业；学校若有机房授权，优先用机房版本 |
| 字体 | **微软雅黑**（Windows 自带）。原型里不要用「苹方 / 思源」等本机缺失字体，否则同学打开会变形 |
| 输入法 | 中文状态下按快捷键容易误触发，建议记牢快捷键后切英文操作 |
| 存放路径 | 纯英文短路径，如 `D:\work\grade-system\`。**不要放在桌面中文长路径或 OneDrive 同步目录**，Axure 对路径长度和云同步比较敏感，容易出现保存失败 |

### 0.2 文件与目录规划

```
grade-system/
├── grade-system.rp          ← Axure 工程文件（唯一需要提交的源文件）
├── prototypes/              ← 发布的 HTML 原型（Publish 生成）
│   └── index.html
└── docs/                    ← 需求规格说明书、导出的说明文档
```

## 1. 新建工程与页面树（Sitemap）

### 1.1 定页面尺寸

【操作】`项目 → 页面样式管理器` → 新建「页面样式」→ 尺寸 `1440 × 900`，命名为 `PC-1440`。
→ 之后每个新建页面在右侧 `样式` 面板选这个样式，**保证 6 个页面宽高完全一致**。

【要点】
- 6 个页面宽高不一致，是新手最常被扣分的地方——原型预览时切换页面会出现滚动条跳动，显得不专业。
- 若你的笔记本是 1920 宽，也别做 1920；1440 在教室投影和大屏上都够用，且不会被压扁。

### 1.2 页面树命名

在左侧 `页面（Pages）` 面板按下面的结构建页面，**编号前缀 + 下划线**保证排序稳定：

```
📁 成绩管理系统
├── 🗂 00_公共
│   └── P0_角色选择（可选）
├── 🗂 01_学生端
│   ├── P1_学生登录
│   ├── P2_成绩查询
│   └── P3_申请查分
└── 🗂 02_班主任端
    ├── P4_添加学生成绩
    ├── P5_修改学生成绩
    └── P6_受理查分申请
```

【要点】
- Axure 默认页面名是 `Page 1`，**必须重命名**。页面名会直接出现在发布的导航和导出的说明文档里。
- 用文件夹（Folder）分组后，发布原型时目录会自动展开，老师找页面很方便。

### 1.3 建立全局参考线（推荐）

【操作】在画布上从左侧标尺拖出参考线：

| 参考线 | 位置 | 用途 |
|---|---|---|
| 内容左边距 | x = 240 | 侧边菜单宽 240px，内容区从这里开始 |
| 内容右边距 | x = 1400 | 内容区右侧留 40px |
| 顶部导航底边 | y = 64 | 顶部导航高 64px |
| 内容区起始 | y = 104 | 导航下留 40px 间距 |

【要点】用 `视图 → 参考线 → 锁定参考线` 防止误拖。全项目统一边距 = 视觉一致性的最低成本做法。

## 3. 母版（Master）—— 一次做，六页复用

母版是本作业**性价比最高**的一步：做 3 个母版，后面 5 个页面的框架就是拖一下的事，而且「所有页面风格统一」是评分点。

### 3.1 要建的母版清单

| 母版名 | 内容 | 类型 |
|---|---|---|
| `M_顶部导航` | 左：系统 Logo + 「成绩管理系统」；右：「欢迎，张三」+「退出登录」 | 普通母版 |
| `M_侧边菜单_学生` | 成绩查询 / 申请查分 / 个人中心 | 普通母版 |
| `M_侧边菜单_教师` | 受理查分申请 / 添加成绩 / 修改成绩 / 成绩统计 | 普通母版 |
| `M_页脚` | 版权信息，高 40px | 普通母版 |
| `M_弹窗_确认` | 居中弹窗：标题 + 提示文字 + 取消/确定 | 普通母版 |
| `M_提示_成功` | 绿色提示条：✓ + 文案，宽 320 高 44 | 普通母版 |

【操作】选中顶部导航的所有元件 → `Ctrl + Alt + M` → 命名 `M_顶部导航` → 勾选**「锁定到浏览器边缘」的顶部固定**（`固定到浏览器 → 顶部`）。
【要点】母版里凡是需要每页不同的区域（如「欢迎，张三」、当前菜单高亮），要**先做在母版里并命名**，再用「母版覆盖（Override）」在具体页面上改文字。用覆盖而不是复制粘贴，才能保持母版可统一更新。

### 3.2 侧边菜单的高亮怎么做

侧边菜单的「当前页高亮」是新手卡点。三种做法，按能力选：

| 做法 | 操作 | 优缺点 |
|---|---|---|
| A. 每页单独放（最简单） | 不做母版，每个页面各自画一个菜单，把当前项填成主色 | 快，但改菜单要改 6 次 ❌ |
| B. 母版覆盖（推荐） | 菜单项做成元件，在母版里给每个菜单项加**选中交互**；页面上用 `母版覆盖` 把当前项设为选中态 | 平衡，够用 ✅ |
| C. 动态面板 + 全局变量（进阶） | 菜单放进 3 个状态的动态面板，`OnPageLoad` 时根据全局变量 `CurrentMenu` 设置面板状态 | 最专业，但要写用例 ⭐ |

> **建议**：时间紧用 B，想拿高分用 C。B 的具体操作：把「成绩查询」等菜单项做成一个「交互样式」为选中的矩形组 → 在页面上双击母版进入编辑 → 只改这一页要高亮的项。

### 3.3 顶部导航的公共交互

| 元件 | 触发 | 动作 |
|---|---|---|
| `btn_退出登录` | 单击 | 1. 弹出确认弹窗（显示 `dp_退出确认`）；2. 弹窗内「确定」→ `打开链接 → P1_学生登录`；3. 同时 `设置变量值`：把 `LoginUser` 清空 |

## 4. 搭页面的通用套路（六页都这么干）

### 4.1 内容区的标准四段式

所有数据类页面（P2 / P4 / P5 / P6）统一用这个结构，**一致性直接拿分**：

```
┌─────────────────────────────────────────────────────────────┐
│  M_顶部导航（母版，高 64）                                    │
├──────────────┬──────────────────────────────────────────────┤
│              │  ① 面包屑 / 页面标题区（高约 56）              │
│ M_侧边菜单    │  ─────────────────────────────────────────── │
│ （母版）      │  ② 筛选区（白卡片，高约 80）                  │
│ 宽 240       │  ─────────────────────────────────────────── │
│              │  ③ 工具栏（按钮 + 计数，高约 44）              │
│              │  ④ 数据区（表格，自适应剩余高度）              │
│              │  ⑤ 分页（居右，高 48）                        │
│              │  M_页脚                                       │
└──────────────┴──────────────────────────────────────────────┘
```

【要点】把 ②③④⑤ 各自 `Ctrl + G` 成组并命名 `区域_筛选` / `区域_工具栏` / `区域_表格` / `区域_分页`，再整体放进一个 `dp_内容区` 动态面板——后续要做「加载中 / 空状态 / 有数据」切换时会非常顺。

### 4.2 表格的两种画法

**方法 A：静态表格（P1 之前先练手，或时间紧张时用）**

【操作】拖「表格」元件 → 设 10 行 × 9 列 → 逐格填文字 → 设置「单元格内边距 12」「行高 44」「表头背景 `#EDF2F7`」「隔行变色 `#F7FAFC`」。

**方法 B：中继器 Repeater（推荐，明显加分）**

中继器能让你的原型**真正有数据驱动感**，演示时老师一看就知道你懂原理。

【操作步骤】
1. 拖入「中继器」→ 双击进入编辑 → 默认是 3 列。删到只剩 1 列，然后按你的列数摆放文本标签。
2. 布局：选中中继器里的文本标签行 → 在 `样式 → 布局` 里设 **「水平排列」「整行换行（Wrap）」「间距 0」**，形成一行 9 列。
3. 给每个列文本改名为 `col_课程名` 等，并绑定数据集列名 `[[Item.课程名]]`。
4. 中继器右侧 `数据集` 面板 → 建列：`课程号 / 课程名 / 学分 / 平时 / 期末 / 总评 / 绩点 / 状态` → 逐行填 5~8 条示例数据。
5. **行内按钮**：在行末尾放一个「申请查分」按钮，`OnClick → 打开链接 → P3`，并加 `设置变量值` 把 `[[Item.课程号]]` 存进变量 `SelectedCourse`。
6. **空状态**：中继器 → `属性 → 每页项目数 10`；空数据时中继器不显示，另放一个 `dp_空状态` 在下方，初始隐藏。
7. **筛选**：`ddl_学期` 的 `OnChange → 添加筛选 → 中继器 tb_成绩列表 → 规则：Item.学期 == 学期下拉的选中项`。

【要点】
- 中继器的列宽总和必须等于中继器宽度，否则会出现错行的「鬼影」。
- 中继器里的元件**不能用绝对 x/y 思维去拖**，要依赖自动排列；一旦混用手工摆放，增加数据行时会错位。

### 4.3 表单与校验的标准做法

错误提示不要用「系统弹窗」，要用**输入框下方的红字**，这是更接近真实产品的做法：

1. 在每个输入框下方放一个文本标签，文字设为「请输入学号」，颜色 `#E53E3E`，字号 12，**初始设为隐藏**。
2. 给输入框设「错误状态」交互样式：边框 `#E53E3E`。
3. 在 `btn_登录` 的 `OnClick` 里按顺序加**条件用例（Case）**：

| 用例 | 条件 | 动作 |
|---|---|---|
| Case 1 | `ipt_学号` 的文字 == `""` | ① 显示 `lbl_学号错误` ② `设置选中 → 错误状态` ③ `等待 0ms`… 最后 `结束` 不再往下走 |
| Case 2 | `ipt_密码` 的文字 == `""` | 同上，针对密码 |
| Case 3 | `ipt_学号` == `"2021001"` 且 `ipt_密码` == `"123456"` | ① `设置变量值 LoginUser = ipt_学号` ② `打开链接 → P2` |
| Case 4（否则） | 无 | 显示 `lbl_登录错误`「账号或密码错误，请重新输入」 |

【要点】条件用例是从上往下匹配的，**把校验放在跳转之前**，并在校验用例末尾加 `其他情况 → 无动作 + 停止`（用「禁用后续用例」或调整顺序），否则空值也会跳转成功。

### 4.4 弹窗的标准做法

1. 新建动态面板 `dp_受理弹窗`，尺寸 `560 × 460`，位置居中（x=440, y=220）。
2. 面板里放：标题文本、关闭按钮 ×、内容区、底部「取消 / 确定」按钮。
3. **面板初始状态设为「隐藏」**（右侧 `属性 → 隐藏`）。
4. 打开：`btn_受理.OnClick → 显示 dp_受理弹窗 → 效果：淡入 200ms`。
5. 关闭：`× 和 取消.OnClick → 隐藏 dp_受理弹窗`。
6. 想让背景变暗：在动态面板下面再放一个 `1440×900` 的半透明矩形（填充 `#000000`、透明度 40%），也初始隐藏，和弹窗一起显示 / 隐藏。

【要点】弹窗必须**盖在所有内容之上**，所以在 `大纲` 里的层级要放在最上面（`Ctrl + ]` 上移）。

## 5. 六个页面的交互清单（照着连就行）

> 「触发」= 在哪操作；「动作」= Axure 里的操作类型；「目标/值」= 具体对象。`[[ ]]` 表示表达式。

### P1 学生登录

| # | 触发 | 动作 | 目标 / 值 |
|---|---|---|---|
| 1 | 页面载入 `OnPageLoad` | 设置文本 | 若 `LoginUser` 非空则回填 `ipt_学号` |
| 2 | `btn_登录` 单击 | 显示 / 设置选中 / 打开链接 | 见 §4.3 的四个用例 |
| 3 | `ipt_密码` 按键松开 | 条件：按键 == `Enter` → 触发 `btn_登录` 的单击 | — |
| 4 | `btn_忘记密码` 单击 | 显示 → 淡入 | `dp_忘记密码提示` |
| 5 | `img_验证码` 单击 | 设置图片 | 换一张占位图（模拟刷新） |

**全局变量**：`LoginUser`（默认空）、`Role`（默认空）、`CurrentMenu`（默认空）。

### P2 成绩查询

| # | 触发 | 动作 | 目标 / 值 |
|---|---|---|---|
| 1 | 页面载入 | 设置文本 | `lbl_欢迎语` = `欢迎，[[LoginUser]]` |
| 2 | `ddl_学期` 改变时 | 添加筛选 | `tb_成绩列表`：`Item.学期 == 选中项` |
| 3 | `btn_查询` 单击 | 添加筛选 | `Item.课程名` 包含 `ipt_关键字` 的文字 |
| 4 | `btn_重置` 单击 | 移除筛选 + 设置文本 | 清空关键字、学期回到「全部」 |
| 5 | 行内 `btn_申请查分` 单击 | 设置变量值 + 打开链接 | `SelectedCourse = [[Item.课程号]]` → P3 |
| 6 | 页面载入 | 设置文本 | `lbl_平均分` = 中继器的 `[[Item.总评.sum() / Item.总评.length]]`（近似即可，或用固定示例值） |
| 7 | 总评列 | 载入时 | 用「设置文本 + 条件用例」实现 <60 红 / 60~79 橙 / ≥80 绿的着色 |

【要点】中继器的 `sum()` / `length` 只有在「中继器数据集」上才可用；如果你算不出来，就**直接写死示例值**并在页面注释里说明「统计值由后端计算」——原型阶段完全可以接受，不要在这里卡超过 20 分钟。

### P3 申请查分

| # | 触发 | 动作 | 目标 / 值 |
|---|---|---|---|
| 1 | 页面载入 | 设置文本 | `ddl_课程` 默认选中 `SelectedCourse` |
| 2 | `ddl_课程` 改变时 | 设置文本 | `lbl_原成绩` = 该课程的示例原成绩（先写死映射） |

| 5 | `dp_提交成功` 的「知道了」 | 隐藏弹窗 + 中继器添加行 | `tb_我的申请` 新增一行，状态 = `待受理` |
| 6 | 快捷理由标签单击 | 设置文本 | `ipt_申请理由` = `[[This.text]]` |

### P4 添加学生成绩

| # | 触发 | 动作 | 目标 / 值 |
|---|---|---|---|
| 1 | `ddl_班级` 或 `ddl_课程` 改变时 | 添加筛选 / 设置面板状态 | 中继器加载该班名单；未选时显示 `dp_空状态` |
| 2 | `ipt_平时`、`ipt_期末` 失焦 `OnLostFocus` | 设置文本 | `col_总评` = `[[Math.round(平时*0.4 + 期末*0.6)]]` |
| 3 | 同上 | 条件用例 | 值 >100 或 <0 → 设置为 0 并显示红字提示 |
| 4 | `btn_保存` 单击 | 条件 + 提示 | 至少一条有效 → 显示 `dp_保存成功`；否则显示警告 |
| 5 | `btn_保存` 成功 | 设置文本 + 中继器更新行 | 进度 `已录入 [[n]] / 共 [[m]] 人` |
| 6 | `btn_重置` 单击 | 设置文本 | 把所有成绩输入框置空 |

【要点】「批量录入 + 自动算总评」是 P4 的**功能核心**，一定要把这个 `OnLostFocus` 的表达式交互做出来，答辩时这是最直观的加分点。

### P5 修改学生成绩

| # | 触发 | 动作 | 目标 / 值 |
|---|---|---|---|
| 1 | `btn_查询` 单击 | 显示 + 设置文本 | 显示 `区域_成绩对照`，把原成绩填入只读列 |
| 2 | `ipt_新成绩` 失焦 | 条件用例 | 非 0~100 整数 → 显示 `lbl_成绩错误` |
| 3 | `btn_保存` 单击 | 校验 + 显示弹窗 | 原因 <5 字 → 显示错误；否则显示 `dp_二次确认` |
| 4 | `dp_二次确认` 的「确定」 | 隐藏弹窗 + 中继器添加行 | `tb_修改记录` 新增：时间 `[[Now.getFullYear()]]-…`、修改人 `[[LoginUser]]`、原值、新值、原因 |
| 5 | `btn_取消修改` 单击 | 设置文本 | 新成绩回退为原成绩 |

【要点】「二次确认 + 修改记录留痕」是这一页在**业务价值**上的亮点，务必做出来并在需求规格说明书里对应到 FR-P5-05 / 06。

### P6 受理查分申请

| # | 触发 | 动作 | 目标 / 值 |
|---|---|---|---|
| 1 | 页面载入 | 设置文本 | `lbl_待办角标` = `[[tb_待受理.itemCount]]` |
| 2 | `tab_待受理` / `tab_已受理` 单击 | 设置面板状态 | `dp_申请列表` 切到对应状态（状态名与标签一致） |
| 3 | 行内 `btn_受理` 单击 | 设置变量 + 显示弹窗 | `CurrentAppeal = [[Item.申请编号]]`；显示 `dp_受理弹窗` |
| 4 | `rb_更正成绩` 选中 | 显示 / 隐藏 | 显示 `ipt_更正分数`，否则隐藏 |
| 5 | `dp_受理弹窗` 的「确定受理」 | 条件用例 | 处理意见为空 → 提示；选择更正但分数为空 → 提示；否则继续 |
| 6 | 受理成功 | 隐藏弹窗 + 中继器删除行 + 添加行 | 从待受理删除 → 已受理中继器新增一行，状态 `已受理` |
| 7 | `btn_驳回` 单击 | 显示弹窗 | 弹出驳回理由输入，确定后状态改 `已驳回` |

【要点】「从待受理列表移除、出现在已受理列表」这个**跨中继器搬行**的动作用两个中继器 + `删除行` / `添加行` 实现，是 6 页里技术含量最高的一处，做出来很容易被老师记住。

## 6. 全局变量与常用表达式

### 6.1 变量表

【操作】`项目 → 全局变量` → 新建。

| 变量名 | 默认值 | 用途 | 在哪设置 | 在哪读取 |
|---|---|---|---|---|
| `LoginUser` | （空） | 当前登录账号 | P1 登录成功 | 所有页面欢迎语、修改人 |
| `Role` | （空） | `STUDENT` / `TEACHER` | P1 登录成功 | 菜单显示判断 |
| `SelectedCourse` | （空） | P2 带到 P3 的课程号 | P2 行内按钮 | P3 课程下拉默认值 |
| `CurrentAppeal` | （空） | P6 当前受理的申请编号 | P6 受理按钮 | P6 弹窗标题 |
| `CurrentMenu` | （空） | 当前菜单项（进阶高亮用） | 各页面 `OnPageLoad` | 侧边菜单母版 |

### 6.2 常用表达式速查

| 需求 | 表达式 | 说明 |
|---|---|---|
| 取输入框文字 | `[[ipt_学号.text]]` 或 `[[LVAR1]]`（局部变量） | 建议在用例里先「设置局部变量 LVAR1 = 元件文字」再用 |
| 算总评 | `[[Math.round(LVAR1*0.4 + LVAR2*0.6)]]` | 见 §5 P4 |
| 算绩点 | `[[LVAR1 < 60 ? 0 : (LVAR1 - 50) / 10]]` | 三元表达式 |
| 字数统计 | `[[LVAR1.length]] + "/200"` | 见 §5 P3 |
| 当前日期 | `[[Now.getFullYear()]]-[[Now.getMonth()+1]]-[[Now.getDate()]]` | 月份要 +1（JS 从 0 开始） |
| 中继器行数 | `[[tb_成绩列表.itemCount]]` | 角标、计数 |
| 中继器某列求和 | `[[tb_成绩列表.Item.总评.sum()]]` | 统计值 |
| 字符串包含 | `[[LVAR1.indexOf("张") > -1]]` | 搜索筛选 |

【要点】Axure 的表达式是 **JavaScript 子集**，`Math.*`、`String.length`、`indexOf`、`Now` 都能用；但**不支持箭头函数、不支持 `let/const`**，别写复杂逻辑，复杂逻辑写进页面注释说明「由后端实现」。

## 7. 页面注释与说明（写文档时能省一半时间）

### 7.1 元件注释（Notes）

选中元件 → 右侧 `说明（Notes）` 面板 → 填写：

```
【需求编号】FR-P2-06
【说明】总评成绩 < 60 时以 #E53E3E 显示，60~79 用 #ED8936，>= 80 用 #38A169
【来源】需求规格说明书 4.2 节
```

### 7.2 页面注释

`页面 → 说明` 面板填写该页的入口、出口、前置条件、后置条件。

### 7.3 导出说明文档

【操作】`文件 → 导出 → 说明文档为…` → 可选 Word / CSV / HTML。
- 选 **Word**：适合直接贴进需求规格说明书，会自动带上页面缩略图、元件注释和交互描述。
- 选 **CSV**：适合整理成需求追踪矩阵（需求编号 ↔ 页面 ↔ 元件）。

【要点】把「元件注释里写了 FR 编号」+「导出说明文档」这两件事做掉，你的需求规格说明书就有了**需求追溯**能力，这是很多小组忽略的加分项。

## 9. 建议制作顺序（按这个顺序，不返工）

| 阶段 | 任务 | 预计耗时 | 完成标志 |
|---|---|---|---|
| ① | 建工程、定页面尺寸、建页面树、拖参考线 | 20 min | 6 个空页面已建好且尺寸一致 |
| ② | 定颜色 / 字号规范，记在便利贴或本文档 | 15 min | 颜色表已确定 |
| ③ | 做 6 个母版（顶部导航、两个侧边菜单、页脚、弹窗、提示条） | 60 min | 母版能拖到任意页面且不错位 |
| ④ | P1 登录页（最简单的先做，练手元件与校验） | 40 min | 空值校验 + 跳转可用 |
| ⑤ | P2 成绩查询（练中继器，最关键） | 90 min | 中继器能筛选、能跳 P3 |
| ⑥ | P3 申请查分（复用 P1 的表单经验） | 50 min | 提交后列表能新增一条 |
| ⑦ | P4 添加成绩（自动计算是核心） | 70 min | 输入平时/期末后总评自动出现 |
| ⑧ | P5 修改成绩（复用 P4 思路 + 二次确认 + 留痕） | 50 min | 修改记录能新增 |
| ⑨ | P6 受理申请（最难，放最后） | 80 min | 待受理 → 已受理能搬行 |
| ⑩ | 全流程走查 + 统一间距 / 对齐 + 填注释 | 60 min | 六页风格一致，演示路径通畅 |
| ⑪ | 发布 HTML + 导出说明文档 | 30 min | `index.html` 可双击打开 |

**总计约 9 小时**，建议拆成 3 次（母版 + P1P2 / P3P4P5 / P6 + 走查发布），每次结束前发布一次留档。

## 10. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 预览时切换页面滚动条乱跳 | 页面尺寸不一致 | 统一用 `PC-1440` 页面样式 |
| 中继器数据行错位 | 列宽总和 ≠ 中继器宽度；或行内元件混用了手工摆放 | 设为水平排列 + 整行换行，列宽精确求和 |
| 母版改了但页面没变 | 页面上对该母版做了「断开（Detach）」或覆盖过多 | 检查页面上的母版是否显示「已覆盖」标记；避免不必要的覆盖 |
| 元件点不到 / 连不上交互 | 被上层透明元件盖住，或元件被锁定 | `大纲` 面板里检查层级，用 `Ctrl + ]` 上移；解锁 |
| 交互没执行 | 条件用例顺序错误，前面的用例已拦截；或忘记 `OnPageLoad` | 用例从上到下匹配，把「其他情况」放在最后 |
| 文字在别人电脑上变形 | 用了本机专有字体 | 统一微软雅黑 |
| 发布后样式丢失 | 发布时未包含图片 / 字体文件 | 发布时保持默认勾选，整体打包成 zip 提交 |
| 文件打不开 / 保存失败 | 路径含中文、过长，或放在云同步目录 | 移到 `D:\work\` 这类纯英文短路径 |
| 预览里中文字体发虚 | 浏览器缩放不是 100% | `Ctrl + 0` 复位缩放 |
