# Axure RP 9 元件坐标清单

> 用途：在 Axure 里**照着这张表敲数字**，不用自己量。每个元件的 `名称 / 元件类型 / X / Y / 宽 / 高 / 文字` 都给了，
> X/Y/W/H 直接填进右侧 **位置和大小** 面板，名称填进 **元件名称**（大纲面板和大纲里能看到），文字直接粘。
>
> 本清单按 **Axure RP 9** 的实际界面写（你机器上装的是 RP 9.0）。
> 配套：`docs/02-axure-guide.md`（怎么做交互）、`docs/03-wireframe-spec.md`（每个元件干什么）。

---

## 0. 怎么用这份清单（按这个顺序做）

| 步骤 | 做什么 | 说明 |
|---|---|---|
| ① | 建页面样式 `PC-1440`，尺寸 **1440 × 900** | 项目 → 页面样式管理器 → 新建；P5 单独改成 1440×1000（见 §9） |
| ② | 按 §1 建 7 个页面，命名 `P1_学生登录` … `P6_受理查分申请` | 左侧页面面板里改名字 |
| ③ | 按 §2 ~ §4 做 **4 个母版**，拖到登录后的 5 个页面上 | 母版做一次，5 页复用，能省一半时间 |
| ④ | 逐页按表格顺序建元件，**先建大的容器卡片，再建里面的小元件** | 顺序对了，分组和层级就不会乱 |
| ⑤ | 数字直接敲进 **位置和大小** 面板（X / Y / 宽 / 高） | 不要用鼠标拖，拖不准 |
| ⑥ | 名称填进 **元件名称** | 后面连交互时靠它找元件，别用默认的 `矩形 1` |
| ⑦ | 按 §11 的层级顺序调叠放次序（`Ctrl + Shift + ]` 上移） | 弹窗必须压在最上层 |
| ⑧ | 最后按 §12 对照检查 | — |

**RP 9 快捷键**：`Ctrl+G` 组合 ｜ `Ctrl+Shift+G` 取消组合 ｜ `Ctrl+Alt+M` 转为母版 ｜ `F5` 预览 ｜ `Ctrl+Shift+]` 置于顶层。

**填写技巧**：敲完一个元件后按 `Ctrl+D` 复制再改 X 坐标，比从头建快得多（表格的行、菜单项、统计项都适合这么干）。

## 1. 全局坐标系统（先记这几个数，后面全靠它）

```
页面          1440 × 900
顶部导航      y  0 → 64      高 64，通栏
侧边菜单      x  0 → 240     宽 240，y 从 64 到页底
内容区        x 240 → 1440
内容左内边距  24
内容起点      x = 264        ← 后面所有卡片的 X 都是 264
内容可用宽    1152           (264 + 1152 = 1416，右边距 24)
```
