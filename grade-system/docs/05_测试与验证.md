## 4. 自动化验证

### 4.1 后端 API

```cmd
python tools\smoke_test.py
```

覆盖登录、选项、成绩、查分提交/重复校验、受理更正、驳回、批量录入、锁定校验。

### 4.2 用户侧页面

前置：Edge 以 `--remote-debugging-port=9222` 启动，`user-front` 运行在 5173。

```cmd
node tools\ui_smoke.mjs
```

检查学生成绩页、教师受理页、添加成绩页、修改成绩页是否渲染出真实数据，并保存截图到 `report/assets`。

### 4.3 管理端页面

```cmd
node tools\admin_ui_smoke.mjs
```

检查「成绩管理」菜单、成绩/查分申请/学生生成页面，并保存截图。

## 6. 数据恢复

测试会写入申请/成绩/修改记录。恢复初始演示数据：

```cmd
mysql -uroot -p123456 --default-character-set=utf8mb4 ry-vue < db\02_seed_grade.sql
```

门户账号和菜单不受影响；如需全量重建，执行 `db/00_grade_system_all.sql`。
