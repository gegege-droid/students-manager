# ruoyi-generator 操作手册（实验三）

## 1. 配置

文件：`backend/ruoyi-generator/src/main/resources/generator.yml`

```yaml
gen:
  author: grade-team
  packageName: com.ruoyi.system
  autoRemovePre: true
  tablePrefix: edu_
  allowOverwrite: false
```

- `autoRemovePre=true + tablePrefix=edu_`：`edu_score` → 类名 `Score`、businessName `score`；
- 必须**先修改配置并重启后端，再导入表**；`className` 在导入时由 `GenUtils.initTable` 计算，导入后再改配置不会自动重算；
- 如果已经导入，先清空 `gen_table` / `gen_table_column`，再重新导入。

## 2. 页面操作流程

1. 启动后端，浏览器打开管理端 http://localhost:8081 ，`admin/admin123` 登录；
2. 系统工具 → 代码生成 → 导入；
3. 勾选 7 张表并确认：
   - `edu_score` 学生成绩
   - `edu_appeal` 查分申请
   - `edu_course` 课程信息
   - `edu_student` 学生信息
   - `edu_teacher` 教师信息
   - `edu_classroom` 班级信息
   - `edu_score_change_log` 成绩修改记录（只用于生成 domain/mapper，不挂菜单）
4. 编辑每张表：
   - 基本信息：类名/业务名/功能名/作者；
   - 字段信息：列表、查询、编辑、新增、必填、显示类型；
   - 生成信息：模板 `crud`、包路径 `com.ruoyi.system`、模块名 `system`、业务名、功能名；
   - **上级菜单**：选择「成绩管理」（menu_id 2000）；
5. 预览代码，确认 `ScoreController` 的 `@RequestMapping("/system/score")`、Vue `views/system/score/index.vue`、菜单 SQL 正常；
6. 下载 `ruoyi.zip`（或批量生成）。

> 注意：菜单 SQL 的父级来自 `params.parentMenuId` 序列化后的 `options`，只设置页面上的 `parentMenuId` 字段而不提交 `params` 时，菜单会挂到默认「系统工具」下。使用 `tools/gen_admin.py` 会自动写入 `params.parentMenuId=2000`。

## 3. 生成文件落位

生成包默认下载并解压到本地 `generated/unzipped`。文件对应位置如下。

| 生成文件 | 目标位置 |
|---|---|
| `main/java/com/ruoyi/system/domain/*.java` | `backend/ruoyi-system/src/main/java/com/ruoyi/system/domain/` |
| `main/java/com/ruoyi/system/mapper/*.java` | `.../system/mapper/` |
| `main/java/com/ruoyi/system/service/*.java` | `.../system/service/` |
| `main/java/com/ruoyi/system/service/impl/*.java` | `.../system/service/impl/` |
| `main/java/com/ruoyi/system/controller/*.java` | `.../system/controller/` |
| `main/resources/mapper/system/*.xml` | `backend/ruoyi-system/src/main/resources/mapper/system/` |
| `vue/api/system/*.js` | `backend/ruoyi-ui/src/api/system/` |
| `vue/views/system/<business>/index.vue` | `backend/ruoyi-ui/src/views/system/<business>/` |
| `*Menu.sql` | 汇总到 `db/04_menu_grade.sql` |

生成器默认把 Controller 放在 `com.ruoyi.system.controller`（ruoyi-system 模块），而不是 ruoyi-admin；`RuoYiApplication` 扫描 `com.ruoyi` 全部子包，因此无需额外注册。

## 4. 菜单与权限

`db/04_menu_grade.sql` 先创建父目录：

```sql
(2000, '成绩管理', 0, 5, 'grade', null, ... 'M' ...)
```

再追加生成器输出的 6 个菜单 SQL。每个模块生成 list/query/add/edit/remove/export 六个权限标识，例如：

```
system:score:list / query / add / edit / remove / export
```

admin 角色拥有全部权限；门户学生/教师只调用 `/portal/**`，不分配这些菜单权限。

## 5. 二次开发（成绩管理）

生成后的 `ScoreServiceImpl` 增加了：

- 新增时自动生成 `scoreId`、计算 `totalScore/gpa`、设置 `manualTotal=0`、录入人/时间；
- 修改时按公式重算总评/绩点。

计算工具 `GradeCalc` 位于 `ruoyi-common/src/main/java/com/ruoyi/common/utils/GradeCalc.java`，与用户侧 Portal 服务共用。

## 6. 自动化脚本

```cmd
python tools\gen_admin.py
```

脚本完成：admin 登录 → 导入缺失表 → 编辑菜单父级与列标记 → 批量下载 zip → 解压到 `generated/unzipped`。可重复执行；如需重建生成配置，先清理 `gen_table` 再运行。

## 7. 常见问题

| 问题 | 原因 / 解决 |
|---|---|
| 类名变成 `EduScore` | `autoRemovePre/tablePrefix` 未生效；改配置并重启后重新导入 |
| 菜单出现在「系统工具」下 | 未设置 `params.parentMenuId=2000` |
| 生成页面 404 | Controller 未进入 jar；执行 `mvn clean package`，不要只 `package` |
| 管理端菜单不显示 | 未执行菜单 SQL，或未重新登录刷新路由 |
| 生成页面字段为空 | 列的 `isList/isEdit/isInsert/isQuery` 未设置；用 `gen_admin.py` 重新配置 |
| 主键新增可编辑 | 生成的列标记未设置 `isInsert=0` |
