# 成绩管理门户

Vue 3 学生与教师门户。学生可以查询成绩、查看成绩趋势和预测、提交查分申请。教师可以批量录入和修改成绩、受理查分申请。两种角色都可使用个人中心和 AI 咨询助手。

## 运行

按 [系统部署说明](../README.md) 初始化数据库并启动后端。使用 Node.js 24 在本目录执行以下命令。

```bash
npm ci
npm run dev
```

访问 http://localhost:5173。学生演示账号为 `2021001 / 123456`，教师演示账号为 `T001 / 123456`。开发服务器将 `/api` 请求转发到本机 8080 端口。

运行 `npm run build` 生成 `dist/`。部署时需要将 `/api` 转发到成绩管理后端并移除该前缀。
