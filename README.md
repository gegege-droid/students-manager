# 高中成绩管理系统

新高考「3+1+2」模式下的高中成绩管理系统 —— **Vue 3 + Vite 前端实现**（可运行）+ Axure 原型设计文档。

> 作业要求：「使用 Axure 制作原型，自拟项目需制作至少 6 个不同功能的页面；页面至少包括学生登录、成绩查询、申请查分；班主任添加学生成绩、修改学生成绩、受理查分申请。」

## 二、业务模型：新高考「3+1+2」

| 类别 | 科目 | 满分 |
|---|---|---|
| 必考（3 门） | 语文、数学、外语 | 各 150 |
| 首选（二选一） | 物理 / 历史 | 100 |
| 再选（四选二） | 化学、生物、思想政治、地理 | 各 100 |
| **合计** | 6 门 | **750** |

- 演示班级 `高三(2)班` 6 名学生，含 3 种选科组合：物化生、物生地、史政地。
- **等级**按得分率划分：优秀 ≥85%、良好 ≥70%、及格 ≥60%、待提高 <60%。
- **排名**：班级排名按每次月考总分实排；年级排名为演示环境的估算值（按全年级总分正态分布折算，共 480 人）。
- **月考场次**：第一次 ~ 第七次月考，其中**第七次尚未录入成绩**，专门用于演示「录入月考成绩」页。

## 四、高考成绩预测算法

**加权移动平均 + 趋势修正**，四步：

1. **换算得分率** —— 分数 ÷ 该科满分。语文满分 150、化学满分 100，统一成得分率才能比较与汇总。
2. **加权移动平均** —— 第 i 次月考权重取 `i`（越近的考试越重要），得到基准得分率。
3. **趋势修正** —— 对最近 3 次得分率做最小二乘拟合取斜率，外推 2 次考试，再乘阻尼系数 **0.5**（只采信一半趋势，避免把一次波动放大成离谱预测）。
4. **预测分与区间** —— 预测得分率 × 高考满分 = 预测分；用历史得分率的标准差给出 ±区间；按场次数量与波动幅度给出置信度（高 / 中 / 低）。

参数集中在 `grade-front/src/utils/score.js` 的 `PREDICT_CONFIG`，页面上会展示这三个数字，便于讲解与调参。

> ⚠️ 预测结果仅供参考，不代表真实高考结果。

**演示数据下的结果**：学生 `20230101` 六次月考总分 642 → 649 → 644 → 668 → 665 → 670，预测高考总分 **661 / 750**（区间 634 ~ 688，置信度高）。


走完这条路径，**「学生申请 → 教师受理 → 成绩更正并留痕」的完整闭环**就演示清楚了。更详细的说明见 `grade-front/README.md`。

## 七、关键设计亮点

1. **完整的业务闭环**，不是孤立页面：学生申请 → 教师受理 → 成绩更正 → 修改留痕 → 学生查看结果。
2. **有真正的分析能力**：不只是查分，而是用 6 次月考做得分率趋势分析并预测高考总分，且算法可解释（页面直接展示参数与四步说明）。
3. **成绩修改强制留痕**：原分数不可删除，每次修改记录操作人、时间、原因。
4. **流程状态约束**：成绩处于「查分中」时禁止直接改分，必须先走完受理流程。
5. **选科差异落到数据层**：录入语文时列出全班 6 人，录入生物时只列出选考生物的学生。
6. **零第三方依赖**：不引 UI 框架、不引图表库，趋势图是手写 SVG，构建产物 index.js 约 120 KB（gzip 48 KB）。
