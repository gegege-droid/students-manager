# 学生成绩管理系统

学生可以查询成绩、查看趋势和预测、提交查分申请。教师可以批量录入、修改成绩并受理查分申请。管理端基于 RuoYi-Vue，提供学生、教师、班级、课程、成绩和查分管理。学生和教师可在门户使用 AI 咨询助手。
